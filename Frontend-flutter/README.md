# Costura Ágil - Flutter Frontend

Este diretório contém o novo frontend do projeto Costura Ágil, desenvolvido em Flutter.

## Estrutura Inicial
- `lib/` - Código principal do aplicativo Flutter
- `assets/` - Imagens e recursos estáticos
- `pubspec.yaml` - Gerenciamento de dependências

## Telas a serem implementadas
- Login
- Cadastro
- Dashboard
- Display
- Produção

## Integração
- Comunicação HTTP com backend Node.js
- Autenticação JWT
- Isolamento de dados por usuário

Consulte o arquivo `.github/copilot-instructions.md` para o plano detalhado de migração.
